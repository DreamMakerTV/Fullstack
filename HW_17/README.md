# Rock Portal

## Опис проєкту

Функціональний веб-проєкт "Rock Portal", що демонструє респонсивний дизайн, використання фреймворку Bootstrap 5 та препроцесора SCSS.

## Структура проєкту

- `index.html` — головна розмітка сторінки.
- `scss/style.scss` — вихідний файл стилів (використовує змінні, міксини та вкладеність).
- `css/style.css` — скомпільований файл стилів.
- `images/` — папка із зображеннями.

## Особливості реалізації

- **Адаптивність:** Забезпечено коректне відображення на мобільних пристроях, планшетах та десктопах завдяки сітці Bootstrap та медіа-запитам у SCSS.
- **SCSS:** Код оптимізовано. Використані змінні для кольорів та розмірів, міксини для медіа-запитів і стилізації зображень, а також логічна вкладеність селекторів.
- **Динамічні елементи:** Інтегровано мобільне меню, карусель для відображення рок-легенд та акордеон для новин.

## Інструкція для запуску

1. Завантажити файли проєкту.
2. Відкрити папку проєкту в редакторі коду (наприклад VS Code).
3. Для роботи зі SCSS встановити розширення **Live Sass Compiler** або **Vite**.
4. Натиснути **Watch Sass** на нижній панелі VS Code.
5. Запустити `index.html` у браузері за допомогою **Live Server**.
